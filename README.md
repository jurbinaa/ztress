## 🌟 La Misión: Descomprimir a los Creadores de Ideas

**Zero Stress** no es una aplicación de bienestar genérica. Es un refugio digital creado por **Ulaloud** diseñado específicamente para quienes experimentan una alta demanda cognitiva: desarrolladores, diseñadores, creadores y arquitectos de ideas del mundo. 

La creatividad y la resolución de problemas exigen un esfuerzo metabólico masivo del cerebro. Cuando este esfuerzo se prolonga, el sistema nervioso simpático activa la respuesta de "lucha o huida", elevando el cortisol y bloqueando el pensamiento lateral. **Zero Stress** interviene directamente en este bucle neuroendocrino para restaurar la calma, reducir el ritmo cardíaco y reactivar la claridad mental en minutos.

## 🧠 Respaldado por la Autonómica y Neurociencia

Cada componente de Zero Stress ha sido desarrollado siguiendo principios clínicos de psiconeuroimmunología y tecnología calma (*Calm Technology*):

*   **Activación Vagal Directa:** Los ejercicios respiratorios emplean patrones específicos (como la respiración coherente a 6 ciclos/min) diseñados para maximizar la **Arritmia Sinusal Respiratoria (RSA)**. Esto incrementa la Variabilidad de la Frecuencia Cardíaca (HRV), desactivando el estado de alerta simpático.
*   **Descompresión Laringofaríngea:** Módulos como la terapia de zumbido (*Humming Therapy*) alivian la tensión física acumulada en el músculo cricofaríngeo (responsable de la sensación de "nudo en la garganta" ante la contención emocional) y aumentan el óxido nítrico nasosinusal hasta 15 veces.
*   **Detoxificación Hormonal:** La ciencia demuestra que las lágrimas emocionales contienen hormona adrenocorticotropa (ACTH) y leucina-encefalina (un opioide endógeno). Zero Stress valida somáticamente tus emociones para facilitar el retorno al equilibrio sin estigmas.

## ⚡ Ingeniería de la Serenidad: Arquitectura de Alto Rendimiento

Un retraso en el dibujado o una animación cortada puede activar una sutil respuesta de sobresalto en el sistema visual, saboteando la relajación. Por ello, la UI/UX de Zero Stress sigue estrictos criterios de **Tecnología Calma**:

### 60fps Garantizados (GPU Compositing)
Las animaciones del pacer respiratorio se delegan exclusivamente al hilo del compositor de la GPU mediante la manipulación exclusiva de propiedades de transformación física (`scale`, `opacity`) y la declaración explícita de `will-change`. Se evitan modificaciones de `layout` o `paint` que saturen la CPU.

### Físicas Orgánicas de Muelles
En lugar de transiciones rígidas basadas en curvas Bezier, el pacer respiratorio utiliza físicas de muelles (*spring dynamics*) calibradas científicamente para emular el flujo elástico de los pulmones reales:
*   *Inhalación:* Rigidez (Stiffness) 12, Amortiguación (Damping) 20, Masa 1.2
*   *Exhalación:* Rigidez 8, Amortiguación 24, Masa 1.5

### Accesibilidad Inclusiva y Reducción de Movimiento
*   **Soporte de `prefers-reduced-motion`:** La interfaz detecta automáticamente las preferencias de accesibilidad a nivel del sistema operativo y sustituye los movimientos de escalado de la pantalla por suaves transiciones cruzadas de opacidad (*crossfades*) para proteger a usuarios con desórdenes vestibulares u oído interno.
*   **Contraste WCAG 2.2:** Asegura relaciones de contraste ≥4.5:1 en todos los estados cromáticos y modos de visualización.
*   **Zen Mode:** Oculta automáticamente menús laterales y controles tras 3 segundos de inactividad para proporcionar un lienzo sin contaminación visual.

### Privacidad Local-First Absoluta
Tus datos, respuestas a pruebas psicométricas y notas de reflexión no viajan a ningún servidor externo. Zero Stress opera al 100% de forma local en tu navegador utilizando `localStorage`. Cero cookies de marketing, cero rastreo corporativo, cero fricción de registro.

## 🚀 Stack de Desarrollo

*   **Framework Core:** React 19, TypeScript, Vite
*   **Animaciones:** Framer Motion (v12 / Motion React)
*   **Estilos:** Tailwind CSS v4 con variables semánticas biofílicas desaturadas (Sage Green, Desaturated Teal, Muted Lavender)
*   **Gestión de Estado:** Zustand con persistencia en LocalStorage
*   **Motor de Audio:** Síntesis matemática directa con Web Audio API (libre de latencias y de bucles pregrabados)

## 📦 Instalación y Desarrollo Local

Requisitos previos: [Node.js](https://nodejs.org/) y [pnpm](https://pnpm.io/) instalados.

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/ztress.git
   cd ztress
   ```

2. Instalar dependencias:
   ```bash
   pnpm install
   ```

3. Iniciar el servidor de desarrollo:
   ```bash
   pnpm dev
   ```

4. Construir la versión de producción:
   ```bash
   pnpm build
   ```
